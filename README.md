# 포켓몬 조선 시간여행

**고구려 살수대첩(612)부터 1979년 12·12까지 한국사 20개 시대, 그리고 1860년부터 1945년까지 세계사 21개 시대를 여행하는 「포켓몬 불가사의 던전」풍 비공식 팬게임**

세레비와 함께 부서진 「시간의 꽃」 꽃잎 20장을 찾아 한반도의 역사 속을 여행합니다. 각 시대 사람들과 포켓몬의 소원을 들어주면 꽃잎이 다시 빛나고, 다음 시대로 가는 시간의 문이 열립니다. 이야기는 실제 역사의 흐름을 따라갑니다.

광복(1945) 뒤에는 한국 이야기와 따로, 청일 · 러일 전쟁과 두 차례의 세계 대전을 지나는 **[세계 모드](#세계-모드)**가 열립니다. 세계 시대의 마을은 「포켓몬스터 블랙」의 실제 마을이고, 5세대 포켓몬 156종이 나옵니다.

> 이 게임은 닌텐도·크리처스·게임프리크·스파이크 춘소프트와 관계없는 **비상업 팬게임**입니다. 아래 [저작권 고지](#저작권-고지)를 꼭 읽어 주세요.

## 안드로이드 앱

웹 게임 전체를 앱 안에 담은 안드로이드 버전입니다. **인터넷 없이 플레이**되고, 멀티플레이(함께 하기)만 인터넷이 필요합니다.

### 내려받아 설치하기

**[📱 APK 내려받기 (joseon-poke.apk)](https://github.com/jbh99/joseon-poke-timetravel/releases/latest/download/joseon-poke.apk)** · [릴리스 페이지](https://github.com/jbh99/joseon-poke-timetravel/releases/latest) (같은 파일을 zip으로 묶은 것도 있습니다)

플레이 스토어 밖에서 받는 앱이라 설치할 때 안드로이드가 경고를 몇 번 띄웁니다. 순서대로 누르면 설치됩니다.

1. 휴대폰 **크롬**에서 위 링크를 누릅니다. 기기에 해로울 수 있는 파일이라는 경고가 나오면 **다운로드**를 누릅니다.
2. 다운로드가 끝나면 **열기**를 누릅니다 (또는 내 파일 → 다운로드에서 `joseon-poke.apk`를 누릅니다).
3. 이 출처의 알 수 없는 앱은 설치할 수 없다는 창이 뜨면 **설정** → **이 출처 허용**을 켜고 뒤로 돌아옵니다.
4. **설치**를 누릅니다.
5. Play 프로텍트 창이 뜨면 **앱 검사**를 하거나 **검사 없이 설치**를 누릅니다. '차단됨'으로 나오면 **자세히** → **무시하고 설치**를 누릅니다.

- 삼성 갤럭시에서 **자동 차단**이 켜져 있으면 설치 자체가 막힙니다. 설정 → 보안 및 개인정보 보호 → 자동 차단을 잠시 끄고 설치한 뒤 다시 켜면 됩니다.
- 새 버전이 나오면 같은 방법으로 설치합니다. 기록은 그대로 두고 업데이트됩니다.
- 안드로이드 7.0 이상에서 설치됩니다.

### 앱 화면과 조작

- **화면**: 가로 화면 고정 · 전체 화면. 가운데에 게임, 왼쪽에 이동 패드, 오른쪽에 버튼이 놓여 게임 화면을 가리지 않습니다. 16:9나 태블릿처럼 네모난 화면에서는 게임 화면이 조금 좁아져 버튼 자리를 비웁니다(1.14).
- **이동 패드**(왼쪽 아래 원): 손가락을 대고 밀면 그쪽으로 움직입니다. 화살표가 8개 그려져 있고, 던전에서는 대각선 화살표까지 모두 켜져 8방향으로 움직입니다(마을과 지도는 4방향이라 대각선 화살표가 흐립니다).
- **버튼**: 키보드와 같은 글자가 적혀 있어 화면 아래 안내를 그대로 따르면 됩니다.

  | 버튼 | 기능 |
  |---|---|
  | **Z** 확인 · **X** 취소 | 조사·대화·공격·결정 / 취소 (마을과 던전에서는 게임 메뉴) |
  | **Q W E R** (십자 배치) | 던전에서 기술 1~4. 위 Q · 왼쪽 W · 오른쪽 E · 아래 R의 둥근 버튼마다 그 기술의 **이름 · 범위 · 남은 PP**가 적혀 있습니다 (던전 밖에서는 숨겨집니다) |
  | **Tab** 태그 | 조종할 포켓몬 교대. 한 턴 쉬기는 **메뉴** 안에 있습니다 (키보드는 A) |
  | 오른쪽 위 **메뉴** | 게임 메뉴 · 퀘스트 · 동료 · 던전 지도 · 한 턴 쉬기와 소리 · 속도(1→2→3배) · 멀티 · 구글 로그인 · English · 가이드를 한 화면에 엽니다 |

- 세계 지도의 장소, 대화 선택지, 메뉴는 화면을 직접 눌러 고를 수 있고, 긴 목록은 손가락으로 끌어 넘깁니다. 게임은 화면 전체를 쓰고, 오른쪽 버튼들은 그 위에 겹쳐 있습니다.
- 휴대폰의 **뒤로 가기**는 X와 같습니다. 가이드나 멀티 창은 닫고, 타이틀 화면에서 누르면 앱을 끝냅니다.
- 블루투스·USB 게임패드: A 확인 · B 메뉴 · X/Y/LB/RB 기술 1~4 · LT 방향만 · RT 쉬기 · Start 메뉴 · Select 퀘스트 · 십자키나 왼쪽 스틱 이동.
- 앱을 내려 두면 음악이 멈춥니다. 기록은 휴대폰 안에 저장되고, **구글 로그인**을 하면 내 구글 드라이브의 앱 전용 숨김 폴더를 거쳐 PC 웹 버전과 같은 세이브로 이어집니다(난이도마다 따로).
- 멀티플레이는 웹 버전과 서로 연결됩니다. 앱에서 방을 열면 초대 링크는 GitHub Pages 주소로 만들어집니다.

### 앱 빌드

`mobile/`이 [Capacitor](https://capacitorjs.com) 안드로이드 프로젝트이고, `tools/build_mobile.ps1`이 `web/`을 `mobile/www`로 복사한 뒤 디버그 APK를 만듭니다. JDK 21과 Android SDK가 필요합니다 (스크립트 안의 경로를 자기 PC에 맞게 바꾸세요).

`-Release`는 배포용 APK를 만듭니다. 디버그 빌드와 같은 키(`~/.android/debug.keystore`)로 서명하는데, 구글 로그인이 그 인증서의 SHA-1에 등록되어 있고 이미 설치한 폰에서 그대로 업데이트되기 때문입니다. 이 키를 잃어버리면 기존 설치본을 업데이트할 수 없으니 따로 백업해 두세요.

```powershell
cd mobile; npm install; cd ..
.\tools\build_mobile.ps1          # mobile\android\app\build\outputs\apk\debug\app-debug.apk
.\tools\build_mobile.ps1 -Release # 배포용: mobile\release\joseon-poke.apk, joseon-poke-apk.zip
adb install -r mobile\android\app\build\outputs\apk\debug\app-debug.apk
```

## 조작법

| 키 | 기능 |
|---|---|
| **방향키** | 이동 (던전은 8방향, 대각선은 두 키를 동시에) |
| **Z / Enter / Space** | 조사 · 대화 · 기본 공격 · 결정 |
| **X / Esc / C** | 메뉴 · 취소 (예/아니오 질문에서는 '아니오') |
| **Q W E R** | 던전에서 기술 1~4 사용 |
| **Tab** | **태그**: 던전에서는 조종할 포켓몬을 다음 동료로 교대 (턴 소모 없음), 마을에서는 다음 동료가 앞장서도록 팀 순서를 돌림 |
| **A** (누르고 있기) | 쉬기 · 턴 넘기기 |
| **Shift + 방향키** | 제자리에서 방향만 바꾸기 |
| **J** | 퀘스트 목록 열기 · 한 번 더 누르면 닫기 |
| **P** | 동료 명부 열기·닫기 (마을과 세계 지도에서, 던전 밖에서만) |
| **M** | 던전 미니맵 켜고 끄기 |
| **1 / 2 / 3** | 게임 속도 1배 · 2배 · 3배 |
| **H** | 게임 가이드 열기·닫기 |
| **마우스** | 세계 지도에서 가고 싶은 장소 클릭 · 대화와 선택지, 메뉴 클릭 |

- **X 메뉴 → 설정**에서 소리 켜기/끄기, 화면 아래 조작키 안내 보이기/숨기기, 게임 속도를 바꿀 수 있습니다. 오른쪽 위 **소리** 버튼으로도 바로 끌 수 있습니다.
- **X 메뉴 → 게임 종료**: 마을에서는 기록을 남기고 타이틀로 돌아갑니다. 던전 안에서 끝내면 던전 진행은 저장되지 않고, 마지막으로 마을에 들렀을 때부터 이어집니다.
- 오른쪽 위 **English / 한국어** 버튼을 누르면 게임을 다시 시작하지 않고 대사, 이름, 메뉴가 그 자리에서 바뀝니다.

## 게임 진행

1. **새로운 여행**에서 난이도(쉬움 · 보통 · 어려움, 엔딩 후 챌린지)를 정하고 주인공과 파트너를 고릅니다 (모부기·불꽃숭이·팽도리). 시간을 건너온 탓에 둘 다 **이로치**입니다.
2. **마을**: 머리 위에 **!** 표시가 있는 포켓몬이 메인 퀘스트 상대입니다.
   - **주막**: 회복 · 기록 · 동료 명부
   - **장터**: 도구 사고팔기 (사기 목록 맨 위에서 10개씩 사기, 팔기 목록에서 1개씩 · 10개씩 · 전부, 가진 도구 모두 팔기)
   - **방(榜)**: 의뢰 게시판
   - 많은 시대에 큰 중심 마을과 함께 **두 번째 마을**이 있습니다.
3. **세계 지도**: 마을 출구로 나가면 열립니다. 장소를 클릭(터치)하거나, 방향키를 누르면 그 방향에서 가장 가까운 장소로 옮겨 갑니다. 마우스로 끌거나(드래그) 휠을 굴려 지도를 둘러봅니다. 빨간 표시는 메인 퀘스트, 파란 표시는 맡은 의뢰, 금색 테두리 안의 포켓몬은 그곳에 있는 전설의 포켓몬입니다. 1.12부터 서로 가까이 붙은 장소는 표시와 이름이 겹치지 않게 벌려 놓고, 실제 위치는 작은 점과 선으로 이어 줍니다.
4. **던전**: 층마다 지형이 무작위로 만들어지는 턴제 던전입니다. 계단을 찾아 내려가고, 마지막 층의 보스를 쓰러뜨립니다.
5. 메인 퀘스트를 끝내면 광장의 **시간의 문**이 열리고 다음 시대로 넘어갑니다.
6. 마을에 돌아올 때마다 **자동 저장**됩니다. 저장은 브라우저(localStorage)에 남으니 같은 브라우저에서 **이어하기**를 고르세요.
   - 기록은 **난이도마다 따로** 남습니다. 엔딩을 본 뒤 다른 난이도로 **새로운 여행**을 시작해도 다 깬 기록은 그대로 남고, 같은 난이도로 새로 시작하면 그 난이도의 지금 여행은 타이틀의 **지난 여행**으로 보관되어(1.20, 난이도마다 5개까지) 언제든 골라서 다시 이어 할 수 있습니다. 기록이 여러 개면 이어하기에서 어느 기록으로 이어 할지 고릅니다(엔딩까지 본 기록에는 ★).

메인 스토리만 하면 1배속으로 약 4시간 안팎, 3배속으로 2~3시간쯤 걸립니다 (의뢰는 제외, 플레이 실력에 따라 차이가 큽니다).

## 세계 모드

**1860년 베이징 조약부터 1945년 제2차 세계 대전의 끝까지, 세계사 21개 시대.** 한국 이야기와 따로 이어지는 두 번째 여행입니다.

- **들어가기**: 1945년 이후 한국 시대의 시간의 문에서 **「세계로」**를 고릅니다. 시대 퀘스트를 끝내지 않아도 됩니다(1.26). 처음 들어가면 1860년부터 시작합니다.
- **한국과 오가기**: 세계 시대의 시간의 문에서는 퀘스트를 끝내지 않아도 언제든 **「한국으로 돌아가기」**를 고를 수 있습니다. 한국 이야기와 세계 이야기는 각자 멈춘 곳을 기억해서, 다시 넘어가면 떠났던 시대부터 이어집니다. 새 여행을 시작하면 세계 모드도 1860년부터 다시 시작합니다(1.11에서는 게임을 끄지 않고 새 여행을 시작하면 앞 여행의 위치를 물려받아, 세계 모드가 1915년부터 열리거나 새 챌린지가 전멸해도 끝나지 않았습니다).
- **난이도**: 처음부터 적이 내 팀에서 가장 높은 레벨보다 5~7 레벨 높고, 초반 배려가 없습니다. 어려움(+25%)과 챌린지(전멸하면 여행이 끝남) 규칙도 그대로입니다.
- **마을**: 그 시대의 도시를 「포켓몬스터 블랙」의 실제 마을 11곳 가운데 하나로 그렸습니다. 롬의 지도 · 건물 · 이동 데이터를 그대로 읽어서 걸을 수 있는 곳이 원작과 같습니다. 1.12부터 마을 밖(다른 도로의 구역, 걸어서 닿을 수 없는 빈터)은 어둡게 그려서 갈 수 있는 곳이 한눈에 보입니다. 1.13부터 마을의 포켓몬은 서로 **두 칸 이상** 떨어져 서고, 서 있거나 돌아다니는 자리 옆으로 길이 **두 칸 폭**은 남도록 비켜 섭니다(1.12까지는 자리가 모자라면 시간의 문 둘레에 몰려 서서, 좁은 바닷가 마을에서는 길을 막기도 했습니다). 어느 마을에서든 사람이 길을 끊거나 두 칸 길을 한 칸으로 좁히지 않습니다.
- **세계 지도**: Natural Earth 지도 데이터로 그린 동아시아 · 유럽 · 태평양 지도입니다.
- **포켓몬**: 5세대 포켓몬 156종이 블랙의 그림 · 아이콘 · 울음소리 · 능력치 · 기술로 세계 시대의 던전에 나옵니다. 배경 음악도 블랙의 음악입니다.

### 세계 모드의 전설과 최종 보스
- **퀘스트 보스 (1.20)**: 세계 모드의 퀘스트 보스는 **5세대(블랙)의 전설 · 준전설 · 환상의 포켓몬**입니다. 레시라무 · 제크로무 · 큐레무는 한 번, 나머지 열(비크티니 · 코바르온 · 테라키온 · 비리디온 · 케르디오 · 토네로스 · 볼트로스 · 랜드로스 · 메로엣타 · 게노세크트)은 두 시대에 한 번씩 나오고, 처음 이긴 곳에서 동료가 될 수 있습니다(이미 동료면 다시 동료가 되지 않음). 5세대 600족 **삼삼드래**는 1945년 얼어붙은 폐허에서 한 번만 나오고(1.25), 다른 강한 자리는 샹델라 · 타격귀 · 기가이어스 · 두빅굴 · 염무왕 · 대검귀(두 번) · 펜드라 · 액스라이즈와 2페이즈의 불비달마(달마폼) · 불카모스, 남는 자리는 4세대 환상의 포켓몬 **쉐이미 · 마나피**(4번씩)가 맡습니다. 1.19까지 세계 모드에 나오던 전설 중 칠색조 · 라이코 · 앤테이는 한국 시대의 퀘스트(1443 · 1392 · 1019)로, 뮤 · 피오네는 둥지로 옮겼고, 나머지는 한국 시대에서 만납니다.
- **5세대 전설의 2페이즈**: 전용기를 쓰면 몇 턴 동안 맵 곳곳의 붉은 칸에 번개 · 불꽃 · 바위 · 돌풍이 떨어지거나, 성스러운칼 · 신비의칼처럼 땅이 줄을 따라 갈라집니다. **토네로스 · 볼트로스 · 랜드로스**는 2페이즈에서 **영물폼**으로 바뀌며 **모든 능력치와 HP가 20% 오릅니다**(1.20). 블랙 롬에는 케르디오의 각오의 모습과 영물폼 그림이 없어서(블랙2 · 화이트2에서 처음 나옴), 2페이즈는 같은 모습에 빛과 이름으로 나타냅니다.
- **레시라무 · 제크로무 (1.19)**: 천관산 펄기아 수치(이야기 때보다 체력 · 공격 30% 높고 모든 능력치 +20%, 내 팀 레벨을 따름)에 체력 · 모든 능력치 · 공격 상한 · 궁극기를 **10% 더한** 스펙으로, 3페이즈로 싸웁니다. 1페이즈는 평범한 기술만, 2페이즈는 평범한 기술과 궁극기, 3페이즈는 궁극기만 계속 씁니다. 이기고 동료가 되면 궁극기 기술을 가지고 옵니다.
  - **레시라무 · 크로스플레임**: **5초 동안** 위에서 불이 내 위치와 근처 동료를 따라 떨어집니다. 붉게 표시된 칸에 떨어지니 멈추지 말고 움직이세요. 턴과 상관없이 실제 시간으로 흐르고, 대화나 메뉴가 열리면 멈춥니다.
  - **레시라무 · 푸른불꽃**: 붉은 칸에 떨어진 자리에 **파란 불꽃이 5턴 동안 남아**, 그 위에서 턴을 마치면 피해를 받고 화상을 입을 수 있습니다.
  - **제크로무 · 뇌격**: 붉은 칸에 번개가 떨어집니다. 표시를 보고 피할 수 있습니다.
  - **제크로무 · 크로스썬더**: **표시 없이** 5턴 동안 번개가 무작위로 떨어집니다. 피할 수 없으니 HP를 넉넉히 채워 두세요.
- **최종 보스 큐레무**: 1945년의 마지막 퀘스트입니다. 베를린이 그대로 싸움터가 되어 1페이즈 큐레무 → 2페이즈 블랙큐레무 → 3페이즈 화이트큐레무로 싸웁니다. 1.19부터 레시라무 · 제크로무와 같은 체력 · 공격에 모든 능력치 +44%(둘은 +32%)입니다. 블랙큐레무는 레시라무와 제크로무의 궁극기 넷을 번갈아 쓰고, 화이트큐레무는 궁극기만 **두 개씩 동시에** 씁니다. 이기면 항복과 해방의 이야기로 세계 모드가 끝납니다.
- **엔딩 (1.13부터)**: 한국 이야기의 **아르세우스(1979)**와 세계 모드의 **큐레무(1945)**를 **모두** 쓰러뜨려야 엔딩이 열립니다. 나중에 끝낸 쪽의 시간의 문에서 「엔딩으로」를 고르고, 한쪽만 끝냈다면 세레비가 남은 쪽으로 안내합니다. 엔딩의 크레디트와 명예의 전당에도 세계 모드가 함께 나옵니다. 아르세우스만으로는 엔딩을 볼 수 없습니다. 1.15부터는 1.12까지 아르세우스만으로 엔딩을 연 예전 기록도 큐레무를 쓰러뜨려야 엔딩이 열리고, ★와 챌린지 달성도 그때부터입니다(1.13 · 1.14에서는 그런 기록을 엔딩을 본 것으로 쳤습니다).
- **동료**: 전설도, 던전의 일반 보스도 이기면 동료로 맞이할 수 있습니다 (일반 보스는 1.12부터. 챌린지에서는 전설만 동료가 되지 않음).

## 게임 요소

### 도감 (1.11)
- **도감**: X 메뉴 → 도감. 전국(1~649) · 신오(4세대, 펄) · 하나(5세대, 블랙) 도감 순서로 보고, 포켓몬마다 펄 도감과 블랙 도감 페이지(그림 · 분류 · 설명)를 바꿔 볼 수 있습니다. 만난 포켓몬은 「발견」, 동료가 된 포켓몬은 「포획」으로 기록되고, 「전체 보기」로 모든 페이지를 열 수 있어요. 그림을 누르면 울음소리가 납니다. 영어 모드에서는 분류와 설명이 영어로 나옵니다(1.14, 롬의 한국어 설명을 옮긴 것).
- 배경 음악은 포켓몬스터 블랙의 음악으로 바뀌었고, 휴대폰에서는 십자 패드가 게임 화면 안으로 들어가 화면이 커졌고, 메뉴 버튼은 오른쪽 버튼 줄 맨 위로 옮겼습니다.

### 전설의 포켓몬과 보스
- **썬더(676) · 앤테이(1019) · 파이어(1232) · 프리져(1388) · 라이코(1392) · 칠색조(1443)**: 같은 시대 보스 중 가장 강합니다(앤테이 · 라이코 · 칠색조는 1.20부터). 체력이 보통 보스의 약 10배이고, 예고 공격을 모으는 동안에도 계속 공격합니다. 어렵다면 레벨을 올려 다시 도전하세요. 전설의 레벨은 일정 이상 오르지 않습니다.
- **놓친 전설**: 전설의 포켓몬을 그 시대에 동료로 맞지 못하면(만나지 못했거나 보내 주었으면), 다음 시대의 다른 던전에 다시 나타납니다. 그 던전의 마지막 층에서 그 던전의 적과 같은 레벨로 기다리고, 또 놓치면 그다음 시대로 옮겨 갑니다. 그 층에서 기다리는 구출 의뢰의 포켓몬도 그대로 나타납니다(1.16).
- **예고 공격**: 보스가 바닥을 붉게 표시하면 몇 턴 뒤 그 칸에 큰 공격이 떨어집니다. 붉은 칸 밖으로 피하면 보스에게 **빈틈**이 생겨 받는 피해가 1.5배가 됩니다.
- **600족 보스**: 메타그로스(1887), 한카리아스·보만다·마기라스(1950)는 전설의 포켓몬보다 15%쯤 약한 강적입니다 (레벨 +2, 체력·공격·예고 공격이 전설의 85%). 전설이 아니므로 세계 지도에 금빛 전설 표시가 붙지 않습니다(백마고지의 마기라스도 1.8부터).
- **던전 깊이**: 1.8부터 모든 던전은 **4층까지**이고, 보스는 마지막 층(4층)에서 기다립니다 (예전 5~6층 던전: 경성 뒷골목, 청산리 골짜기, 반전세계, 시간의 틈, 경운궁 중명전, 판문점). 천관산과 보스 탑은 단계마다 한 층이라 그대로입니다.
- **일반 보스**: 1200년부터 체력이 30% 늘어나고, 우리 팀이 성장하면 보스 레벨도 함께 오릅니다.

### 2페이즈 · 3페이즈
- **아르세우스**(최종 보스, 3페이즈): 1979년 12·12 뒤 **마지막 퀘스트**인 「천관산」 꼭대기, 시작의 방에서 기다립니다. 레벨은 고정이 아니라 **내 팀의 레벨에 맞춰** 정해집니다(최소 70, 최대 180). 쓰러뜨리면 **황금빛 이로치**로 다시 일어납니다(2페이즈: 체력은 처음의 2/3, 공격과 예고 패턴이 훨씬 거셈). 2페이즈부터 **심판의 뭉치**가 하늘에서 필드 곳곳에 원 모양으로 쏟아집니다. 또 쓰러뜨리면 무지갯빛으로 일어나는 **3페이즈**(체력 절반, 공격 +10% · 방어 +20%)에서는 매 턴 쏟아지는 심판과 **동시에** **파괴광선**을 360도로 한 바퀴 돌리며 세 번 휘두릅니다 (다음에 지나갈 줄기와 심판이 떨어질 칸이 함께 붉게 빛남). 1.9부터 파괴광선이 도는 동안에도 심판이 멈추지 않고, 파괴광선 피해가 **40%** 커졌습니다.
- **다크라이**(1979 12·12 마을 전투, 1979년 전에는 나오지 않음, 3페이즈, 1.8부터 혼자 싸우며 모든 능력치 +25%): **다크홀**(발밑에 열린 검은 구멍에 빠지면 잠듦) → 악몽의 모습(다크홀 · **섀도다이브**) → 칠흑의 모습(공격 +10% · 방어 +20%, **악의파동**까지).
- **레쿠쟈**: 쓰러뜨리면 **메가레쿠쟈**로 다시 일어나 유성을 불러냅니다.
- **테오키스**: 노말폼으로 싸우다 체력이 반 아래로 내려가면 **어택폼**으로, 쓰러뜨리면 **스피드폼**으로 다시 일어납니다 (공격이 잘 맞지 않음).
- **디아루가(1919) · 기라티나(1940) · 펄기아(1945)**: 쓰러뜨리면 **오리진폼**으로 변해 2페이즈를 시작합니다. 1.7에서 이 셋과 **뮤츠**는 **체력 +30% · 공격 +15%**로 강해졌습니다(아르세우스는 1.5의 +10% 그대로).
- **전설의 전용기**: 1페이즈에 한 번, 2페이즈에 두세 번 씁니다. 체력이 그 고비에 닿으면 전용기를 쓰기 전까지는 더 깎이지 않습니다.
  - **디아루가 · 시간의 포효**: 한 턴 기를 모은 뒤 시간을 되감아 **10초 전의 체력**으로 돌아가고, 우리 편 모두의 HP를 최대치의 **33%** 깎으며(1.16까지 20%, 마지막 퀘스트의 디아루가는 1.26부터 25%), 그 피해만큼 체력을 더 회복합니다(1.17). 그다음 턴은 반동으로 쉽니다(빈틈). 1.9부터 처음 모습과 오리진폼 **모두 두 배로 자주** 씁니다 (1919년: 처음 모습 2번 + 오리진폼 4~6번, 천관산: 4번 + 6~8번, 보스 탑: 1919년과 같음).
  - **펄기아 · 공간절단**: 공간이 찢어지며 싸움터가 바깥부터 한 겹씩 **좁아지고**(두 번까지), 바닥 곳곳의 **더 길고 많은 틈**에서 공격이 솟아오릅니다(1.7에서 피해도 0.32 → 0.42). 펄기아는 기술로 **하이드로펌프**도 씁니다.
  - **기라티나 · 섀도다이브**: **어둠 속으로 사라졌다가** 우리 포켓몬의 **그림자 밑에서 튀어나와** 공격합니다. 악 타입에 맞서 격투 기술 **파동탄**도 씁니다. 1.7부터 첫 모습에서 **그림자 폭풍 · 대지의힘 · 용성군 · 파동탄 · 원시의힘**을 번갈아 예고하고, 섀도다이브와 **용의파동**(여덟 방향 파동) 두 전용기를 씁니다.
  - **그란돈 · 단애의 칼 / 가이오가 · 근원의 파동** (1950 서울 시가전의 보스, 1.8부터 모든 능력치 +25%): 갈라진 땅을 따라 바위 칼날이 솟거나, 여덟 방향으로 파동이 퍼집니다. 원래 예고 공격은 대지의 힘 · 하이드로펌프로 이름이 바뀌었습니다.
- **기라티나**는 고스트·드래곤 타입이라 격투 기술은 듣지 않고 물·불꽃 기술은 반감됩니다. 1388년에 동료가 되는 프리져처럼 얼음·드래곤·고스트·악 기술을 쓰는 동료를 데려가세요.

### 천관산 (마지막 퀘스트)과 보스 탑 (보스 모드)
- **천관산**: 1979년 12·12 뒤 장흥의 천관산을 오릅니다. 들어가자마자 **펄기아**, 다음 층에서 **디아루가**가 길을 막습니다. 둘 다 이야기 때보다 **체력과 공격이 30% 더 강하고**, 예고 공격과 전용기를 **1.5배쯤 자주** 씁니다. 1.8부터 천관산의 **펄기아 · 디아루가 · 아르세우스**는 **체력과 모든 능력치가 20%** 더 오릅니다(보스 탑의 능력치는 그대로). 1.7에서 펄기아 2페이즈 도중 게임이 멈추던 문제(오리진폼이 부를 졸개가 없는 던전에서 오류가 나던 것)도 고쳤습니다. 둘을 모두 쓰러뜨리면 **천계의 피리**가 나타나고, 「포켓몬스터 펄」 롬의 실제 지도로 만든 **창기둥** 꼭대기 제단에서 피리를 불면 빛의 계단이 내려옵니다. 계단을 오른 **시작의 방**(역시 펄의 지도)에서 **아르세우스**가 기다리다가, 가까이 다가가면 깨어납니다. 한 번 쓰러뜨린 펄기아·디아루가는 다시 싸우지 않고, 다음 도전은 남은 단계부터 시작합니다.
- **보스 탑**: 1979년의 마지막 퀘스트(아르세우스)를 마치면 1979년 지도(강원도)에 **보스 탑**이 생깁니다. 10층 내내 야생 포켓몬 없이 전설의 포켓몬과만 싸웁니다.
  - 1~5층: 서로의 약점을 덮어 주는 준전설이 **둘씩** 나옵니다. 썬더·프리져, 파이어·스이쿤, 엠라이트·아그놈, 라티아스·라티오스, 레지아이스·히드런 (이야기 때의 능력 그대로). 둘이 함께 나와도 예고 공격은 한 번에 하나씩 옵니다.
  - 6~9층: **뮤츠 · 디아루가 · 펄기아 · 기라티나**가 한 마리씩, 기존보다 **15% 더 강하게**.
  - 10층: **아르세우스**, 역시 15% 더 강하게.
  - 탑의 포켓몬은 **잡을 수 없습니다**. 층을 오를 때마다 HP · PP · 상태 이상이 모두 회복되고, 다음에 들어갈 때는 지난번에 깬 층 다음부터 이어서 오를 수 있습니다. 보스 레벨은 아르세우스처럼 팀 레벨을 따라갑니다.

### 해전 (물 타입만 참가)
살수, 기벌포, 흥화진, 진포, 한산도, 울돌목(명량), 노량, 인천·대동강처럼 물 위에서 벌어지는 싸움에는 **물 타입 포켓몬만** 배에 오릅니다. 1.13부터 지도에서 해전을 고르면 팀과 동료 명부의 물 타입 목록이 열리고, 배에 태울 포켓몬을 **최대 3마리 직접 고릅니다**(고른 순서대로 앞장섬). 팀의 물 타입은 미리 골라져 있고, 목록은 **팀 먼저 · 레벨 높은 순 · 가나다 순**으로 정렬할 수 있습니다. 2마리보다 적게 고르면 모자란 자리를 수군이 빌려주고, 물 타입이 하나도 없으면 바로 2마리를 빌려줍니다. 1.12까지는 팀의 물 타입과 명부에서 레벨이 가장 높은 물 타입이 저절로 탔습니다. 첫 시대에 리아코와 물짱이를 받습니다. 수군이 빌려주는 승무원은 그 레벨에 맞게 진화한 모습(예: Lv 80 장크로다일)으로 옵니다.

1.18부터 **전투 대형**을 정해 두면 고르지 않고 **바로 출격**합니다. 마을이나 세계 지도 메뉴의 **해전 대형**에서 미리 3마리를 고르거나, 출전 목록의 **이 대형으로 고정하고 출발!**을 누르면 됩니다. 그러면 지도에서 해전을 골랐을 때 **바로 출격! / 대형 바꾸기 / 그만두기**만 묻습니다. 팀이 물 타입 3마리일 때도 같습니다.

1.18부터 **해전의 적 레벨은 출전 파티를 따릅니다.** 적과 보스 모두 **출전 파티의 최고 레벨 +3**(어려움 **+5**, 쉬움 +1, 챌린지 +3)이고, 전투 중에 레벨이 올라도 출전할 때의 레벨을 기준으로 합니다. 수군이 빌려주는 승무원도 고른 포켓몬의 최고 레벨로 오고, 아무도 고르지 않았을 때(물 타입이 없을 때)는 팀의 최고 레벨을 기준으로 합니다. 1.17까지는 해전도 육지 던전처럼 뭍에 남은 팀의 최고 레벨을 따랐습니다.

### 새로 생긴 이야기와 장치
- **마을 표시**: 빨간 `!`는 메인 퀘스트, 파란 `!`는 의뢰(새 의뢰나 보고할 의뢰가 있는 방꾼, 배달할 물건을 기다리는 사람), 엽전 표지는 장사꾼, 국밥 표지는 주막 주인, 보라색 디스크 표지는 기술머신 상인입니다.
- **펄 마을**: 1887 제물포(운하시티), 1905 한성(연고시티), 1940 경성(무쇠시티), 1950 흥남(선단시티)과 서울 시가전(장막시티), 1979 서울(들판시티)은 「포켓몬스터 펄」 롬의 실제 마을 배치(이동 가능한 칸, 건물 자리, 물, 문, NPC 자리)를 읽어 본떠 만들었습니다 (`tools/pearl_maps.py`).
- **순사 그라에나 (1905~1944)**: 일제 강점기 마을(1905 한성, 1919 경성·아우내 장터, 1920 용정, 1940 경성)에서는 순사 그라에나 6마리가 **2마리씩 3짝으로 순찰**합니다. 눈에 띄면 다가와 **500냥**을 요구하고(가진 돈이 모자라면 있는 만큼), 내거나 **그 자리에서 맞서 싸울** 수 있습니다(마을이 그대로 싸움터가 되고, 그라에나는 일반 적보다 **12% 강함**). 이기면 그 짝은 마을을 떠나고, 어느 쪽이든 그 방문 동안 다시 붙잡지 않습니다. 멀리 달아나면 쫓기를 포기하고, 말을 걸어 싸움을 걸 수도 있습니다. 독립군 기지와 충칭 임시정부에는 오지 않습니다.
- **밀정 찾기 (1920)**: 전령이 알려 주는 타입과 대략의 몸무게로, 그 타입 포켓몬들을 저울에 달아 밀정을 지목합니다. 잘못 지목하면 3년, 던전에 다녀오면 1년이 흐르고, 1930년까지 못 잡으면 경찰이 기지를 덮쳐 포켓몬이 모두 쓰러지고 처음부터 다시 찾습니다.
- **헤이그 특사 (1905)·카이로·얄타·포츠담 회담 (1940·1945)·10·26 (1979)**: 퀘스트가 아니라 이야기로 나옵니다.
- **마을 전투**: 1950년 서울 시가전과 1979년 12월 12일 밤의 서울은 마을이 그대로 싸움터가 됩니다. 1.8부터 병사들은 나오지 않고 **보스 한 마리**와 싸웁니다. 12·12에서는 **다크라이** 혼자(하나회 쪽 +15%에 더해 모든 능력치 +25%), 서울 시가전에서는 진영에 따라 **그란돈 또는 가이오가**(모든 능력치 +25%)가 보스이고, 내 진영의 전설 **한 마리**가 동료로 함께 싸웁니다. 싸움터에서는 동료가 리더를 따라다니지 않고 **각자 보스에게 달려가 자유롭게** 싸웁니다(순사와의 싸움도 같음).
- **레지 3총사와 레지기가스 (1945 이후)**: 마을의 강철 거인(레지스틸)을 동료로 맞으면 레지락·레지아이스의 굴(보스는 2층)이 지도에 나타나고, 셋을 데리고 가면 선단신전(펄의 실제 신전 지도, 2층)에서 레지기가스를 만납니다.
- **라티아스 · 라티오스 (1945 이후)**: 마을에서 둘 중 하나만 골라 동료로 맞습니다.
- **하늘기둥 (1950 서울 시가전 뒤)**: 그란돈과 가이오가가 맞부딪친 뒤 지리산에 하늘기둥이 나타납니다. 2층에서 **레쿠쟈**를 만나고(3페이즈, 화룡점정), 레쿠쟈를 쓰러뜨리면 모두 회복되어 같은 자리에 **테오키스**가 바로 내려옵니다. 둘 다 동료가 될 때까지 다시 도전할 수 있습니다 (챌린지에서는 닫힘).
- **테오키스 폼체인지**: 테오키스를 얻으면 마을에 **붉은 운석**이 생깁니다. 테오키스를 파티에 넣고 운석을 조사하면 노말폼(공격형) · 어택폼(공격·특공 크게 ↑, 방어 ↓) · 디펜스폼(방어·특방 크게 ↑, 공격 ↓) · 스피드폼(회피 +1) 가운데 고를 수 있습니다. 스프라이트도 파랑구조대 롬의 폼별 그림으로 바뀝니다.
- **레지 초상화**: 파랑구조대 롬에는 레지 3총사와 레지기가스의 얼굴이 없어서, 펄 롬의 전투 그림에서 얼굴을 잘라 같은 형식(40×40, 띠 배경)으로 만들었습니다 (`tools/make_portraits.py`).
- **1950 판문점**: 「시간의 틈」의 마지막 층은 이제 **보만다**가 지키고, 아르세우스는 여행의 맨 끝(1979)으로 옮겨 갔습니다.
- **조정**: 독 피해 절반(매 턴 최대 HP의 1/32), 파이어·프리져 체력과 피해 20% 하향.

### 진영 선택과 그란돈 · 가이오가
1945년 광복 뒤 나라가 갈라질 때 **민주주의 남한**과 **공산주의 북한** 가운데 진영을 고릅니다. 진영마다 1950년의 마을, 동료, 이야기, 해전 던전이 달라집니다. 1950년 서울 시가전에서 북쪽에는 **그란돈**, 남쪽에는 **가이오가**가 서고(내 쪽 전설은 동료로 함께 싸우고, 다른 쪽 전설이 보스), 이기면 내 쪽 전설만 **주홍구슬/쪽빛구슬**과 함께 동료가 됩니다 (다른 쪽은 얻을 수 없고 전투가 끝나면 다시 만날 수 없습니다). 이긴 뒤에는 세계 지도에서 「서울 · 1950년 6월」이 사라집니다(1.11까지는 다시 들어가면 화면이 까맣게 멈췄습니다). 구슬을 던전에서 쓰면 **원시회귀**해 그 던전이 끝날 때까지 능력이 30% 오르고, 낙동강 전선에서는 그란돈이, 인천 앞바다에서는 가이오가가 능력 +20%를 받습니다.

| 진영 | 마을 | 함께하는 포켓몬 |
|---|---|---|
| 남쪽 · 대한민국 | 부산 임시 수도 / 대구 피란민 거리 | 윈디, 킹드라, 피죤투 |
| 북쪽 | 평양 / 흥남 부두 | 링곰, 무장조, 코리갑 |

### 동료
- 쓰러뜨린 야생 포켓몬은 **35%** 확률(이로치는 70%)로 동료가 되고 싶어 합니다. **보스와 전설의 포켓몬은 이기면 반드시** 동료로 맞이할 수 있습니다.
- 파티는 주인공·파트너·동료 1마리, 모두 3마리입니다. 나머지는 **동료 명부**(최대 500마리)에서 기다리며 경험치를 절반씩 받습니다.
- **동료 바꾸기**: 던전 밖(마을·세계 지도)에서 **P**를 누르거나, X 메뉴의 **동료 명부**, 주막 주인에게 말을 걸어 명부를 엽니다. 명부 위쪽의 팀에서 하나를 고르면 서로 자리를 바꾸고, 명부의 포켓몬을 고르면 리더·파트너·동료 중 원하는 자리와 교체합니다. 명부의 동료는 던전에서 불러올 수 없습니다.
- **동료 찾기**: 명부의 **찾기**로 이름 일부, 초성(ㄹㄱㅇ → 루기아), 타입(드래곤), 도감 번호(445), "이로치"를 넣어 원하는 동료만 골라 봅니다. **정렬**은 들어온 순 · 레벨 높은 순 · 도감 번호 순 · 가나다 순입니다.
- **순서 바꾸기**: X 메뉴 → **포켓몬**에서 포켓몬을 고르고 Z를 누르면 **기술 순서 바꾸기**(Q·W·E·R 자리, 던전 안에서도 가능)와 **파티 순서 바꾸기**(리더·파트너·동료 자리, 마을에서만)가 나옵니다. 하나를 Z로 고른 뒤 바꿀 자리에서 Z를 누르면 서로 바뀝니다.
- **최대 레벨 180**: 포켓몬은 본편의 100에서 멈추지 않고 Lv 180까지 오릅니다. 아르세우스도 팀 레벨을 따라 최대 Lv 180이 됩니다. 180이 넘는 적도 동료가 될 때는 **Lv 180**으로 들어오고, 1.19까지 180을 넘게 들어온 동료는 기록을 불러올 때 180으로 맞춰집니다(1.20).
- **기술 배우기**: 레벨이 올라 새 기술을 배울 때 기술이 이미 4개면, 본편 포켓몬처럼 **잊을 기술을 고르거나 배우지 않을** 수 있습니다. 마을에서 X 메뉴 → **포켓몬** → Z → **기술 배우기**를 고르면 지금 레벨까지 배우는 기술을 언제든 배웁니다. 잊었거나 건너뛴 기술도 여기서 다시 배우고, 앞으로 배울 기술과 그 레벨도 볼 수 있습니다.
- **PP 2배**: 1.9부터 내 포켓몬(파티와 동료 명부)의 기술 PP는 원작의 **2배**입니다 (예: 10만볼트 15 → 30). 야생 포켓몬과 보스는 원작 그대로이고, 예전 기록을 불러오면 남아 있던 PP도 2배가 됩니다.
- **PP 회복**: 던전을 나오면(클리어·실패·탈출 모두) 파티의 기술 PP가 모두 찹니다. 던전 안에서는 인삼으로, 마을에서는 주막에서 쉬어도 회복됩니다. 독·화상·마비 같은 **상태 이상**은 마을에 돌아오면 모두 낫습니다.
- **기술 조준**: 우리 편 기술은 4칸 안에 적이 있으면 방향과 상관없이 그 적을 노려 **반드시 맞힙니다**. 더 멀면 바라보는 방향 직선으로 나갑니다(물리 기술은 4칸, 특수 기술은 5칸). 야생 포켓몬의 기술은 직선 **4칸**까지만 닿습니다.
- **리더 뱃지와 동료 따라오기**: 지금 조종하는 포켓몬은 머리 위와 팀 창의 이름 옆에 **리더 뱃지**(왕관 방패)를 답니다. 파트너와 동료는 리더 곁 4칸 안에서 싸우고, 통로에서는 앞 동료 바로 뒤로 줄지어 따라오며, 시야 밖으로 떨어지면 리더 곁으로 따라붙습니다.
- **보스방 부활**: 보스가 있는 층에 들어서면 쓰러졌던 동료가 HP 절반으로 다시 일어납니다. 보스의 기술과 예고 공격은 보스에게서 4칸까지만 닿고(전설의 전용기는 싸움터 전체), 보스는 잠듦·얼음·독에 걸리지 않습니다. **전설의 포켓몬 보스**는 마비·화상까지 모든 상태 이상에 걸리지 않습니다.
- **한 곳에 전설 하나**: 전설의 포켓몬은 장소마다 한 마리씩만 기다립니다. 아그놈 · 유크시 · 엠라이트는 각자의 장소(전라 우수영 · 규장각 · 탑골 공원)로 옮겨 가서, 메인 던전은 한 번 깨면 끝납니다. 마지막 퀘스트인 천관산과 보스 탑만은 층마다 다른 전설이 기다립니다. 놓친 전설도 전설이 없는 던전에만 다시 나타나고, 레지기가스는 1945년 이후 레지 줄기에서만 만납니다.
- **중간 보스**: 발전소(에레키블)는 메인 퀘스트 때 마지막 보스만 나옵니다. 중간 보스는 메인을 깬 뒤 다시 가면 만나는 선택 전투이고, 한 번 이기면 다시 나오지 않습니다.
- **태그(Tab)**: 던전에서 조종하는 포켓몬을 다음 동료로 바꿉니다. 턴을 쓰지 않습니다. 마을에서 누르면 다음 동료가 앞장서도록 팀 순서가 한 칸씩 돌아가고, 던전도 그 포켓몬이 앞장서서 시작합니다. 조종하던 포켓몬이 쓰러지면 남은 동료가 앞장서고, **셋이 모두 쓰러져야** 탐험이 실패합니다. 던전을 클리어하면 쓰러졌던 동료도 기운을 되찾습니다.
- **1층에서 나가기**: 아직 1층이라면 X 메뉴 → **던전에서 나가기**로 대가 없이 되돌아 나올 수 있습니다.

### 엽전과 상점
- 엽전은 쓰러뜨린 적(레벨이 높을수록 많이, 보스는 10배), 바닥에 떨어진 엽전, **던전 클리어 보상**(층수 × 시대), 방(榜) 의뢰 보상으로 모읍니다.
- 셋이 모두 쓰러지면 마을로 돌아오고 엽전의 10%(초반)~30%(후반)를 잃습니다 (챌린지에서는 그 여행이 끝납니다).
- 장터 도구: 오랭열매(HP 30 회복), 자뭉열매(최대 HP의 **55%** + 상태 이상 회복), 주먹밥(HP 80 + 상태 이상 회복), 인삼(PP 회복), 탈출 부적, 돌팔매, 기력의 조각(1000냥: 쓰러진 포켓몬을 HP 절반으로 되살림, 던전 한 번에 하나. 큐레무와의 싸움에서는 둘, 보스 탑에서는 제한 없음).
- 1.10부터 상태 이상만 고치는 **약초**는 팔지 않고 던전 바닥에도 떨어져 있지 않습니다 (가지고 있던 약초는 한 개에 40냥으로 돌려받습니다). 1392년 「북악산 약초 캐기」 의뢰의 약초는 그 의뢰 동안 북악산에서만 나는 의뢰 물건입니다.
- **기술머신**: 마을마다 보라색 디스크 표지를 단 **기술머신 상인**이 있습니다. 4세대 기술머신 가운데 이 게임에서 쓸 수 있는 55개를 팔고, 사는 자리에서 바로 가르쳐 줍니다(기술이 4개면 하나를 잊음). 센 기술(위력 80 이상)은 15000냥, 나머지는 10000냥입니다 (1.13부터, 전에는 3000냥 · 1000냥). 포켓몬 자신의 타입, 레벨업으로 배우는 기술의 타입, 노말 타입 기술머신을 쓸 수 있습니다.

### 난이도
초반 시대는 적이 적게 나오고 약하게 때리며 HP도 빨리 찹니다. 시대가 지날수록 적이 많아지고 세지며, 회복도 느려집니다. 보스는 시대가 갈수록 더 강해지고, 후반 전설은 회복 도구와 타입 상성을 챙겨야 이길 수 있습니다.

- **던전 레벨**: 1200년 전까지, 그리고 팀의 가장 높은 레벨이 20 이하일 때는 던전마다 정해진 레벨입니다. 그 뒤로는 팀에서 가장 높은 레벨보다 **5 ~ 7 레벨 높은** 적이 나옵니다 (1.10부터, 보통 · 어려움 · 챌린지 모두 같고 쉬움은 2 레벨 낮음). 정해진 레벨보다 낮아지지는 않고, 보스는 그 적들의 가장 높은 레벨보다 등급만큼(전설 +3, 600족 +2) 높습니다.
- **일반 포켓몬**: 보스가 아닌 적(야생 포켓몬, 보스가 부른 졸개, 순사 그라에나)은 HP와 모든 능력치가 **80%**입니다 (어려움에서는 여기에 25%가 더해짐). 동료가 되면 원래 능력치로 돌아옵니다.
- **독**: 한 턴에 최대 HP의 1/64만큼 줄어듭니다 (화상은 1/16).

| 난이도 | 내용 |
|---|---|
| 쉬움 | 적 레벨 −2, 적이 주는 피해 −25%, 보스 체력 −20% |
| 보통 | 기본 |

## 직접 실행하기

빌드 과정이 없는 순수 HTML·JavaScript(ES 모듈) 게임입니다. 모듈을 쓰기 때문에 파일을 직접 열면(`file://`) 동작하지 않고, 로컬 웹 서버가 필요합니다.

```bash
git clone https://github.com/jbh99/joseon-poke-timetravel.git
cd joseon-poke-timetravel
python -m http.server 8000 --directory web
```

브라우저에서 http://localhost:8000 을 엽니다.

## English

**Pokémon Joseon Time Travel** is an unofficial, non-commercial Mystery Dungeon-style fan game. With Celebi, you travel through twenty eras of Korean history, from Goguryeo's Battle of Salsu (612) to December 12, 1979, and win back the twenty petals of the Flower of Time. After liberation (1945) a separate **world line** opens: 21 eras of world history, from the Convention of Peking (1860) to the end of the Second World War, set in the real towns of Pokémon Black.

- **Play**: https://joseon-poke-timetravel.netlify.app or https://jbh99.github.io/joseon-poke-timetravel/ in a desktop browser (phones get on-screen buttons). The **English / 한국어** button switches the language live.
- **Controls**:
  - Arrows move; Z/Enter attacks or confirms; X/Esc opens the menu or answers "no"; Q W E R use moves.
  - Tab tags the next teammate in; A (hold) rests; J opens and closes the quest list.
  - P opens the companion roster outside dungeons: search it (name, type, dex number), sort it, and swap anyone into any team slot; 1/2/3 set the game speed.
  - The mouse picks places on the world map, dialogue choices and menu rows; dragging or the wheel scrolls the map.
- **World line (1860–1945)**: from 1945 on, a Korean era's Time Gate offers "To the world" and a world era's leads back to Korea, at any time and with the era's quests done or not; each line resumes where it was left. Foes start 5 to 7 levels above your strongest Pokémon, and every town is one of Pokémon Black's eleven towns drawn from the ROM's maps (what lies outside the town is drawn dim since 1.12). Bosses in **bold** are legendary and mythical Pokémon, the others Unova's strongest and Hydreigon (600-total); (optional) marks a legend's lair off the main quest.
  - From the Convention of Peking to the Russo-Japanese War: 1860 Peking (Opelucid City): the Burning Yuanmingyuan, the Ussuri Frontier: **Shaymin**, **Virizion** (two phases) · 1894 Weihaiwei (Undella Town): the waters off Pungdo and the Battle of the Yellow Sea (naval): **Manaphy**, Seismitoad · 1904 Port Arthur (Driftveil City): Chemulpo and Tsushima (naval), 203 Meter Hill: Samurott, **Terrakion** (two phases), **Thundurus** (Therian Forme).
